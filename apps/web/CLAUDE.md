# @bankql/web

TanStack Start (React 19) web app. Runs SQL queries against FDIC/NIC banking datasets in the browser via DuckDB-WASM, with TanStack Query managing async state, TanStack Table for display, TanStack AI for natural-language queries, and Chakra UI for components.

## Dev Commands

```bash
npm run dev        # vite dev (TanStack Start plugin handles route codegen)
npm run build      # vite build
npm run start      # vite preview
npm run typecheck  # tsc --noEmit
```

## File Layout

```
app/
  routes/
    __root.tsx       # root layout — ChakraProvider, QueryClientProvider, DuckDBProvider
    index.tsx        # home route
    routeTree.gen.ts # auto-generated by tsr — do not edit
  lib/
    duckdb.tsx       # DuckDB-WASM context, DuckDBProvider, useDuckDB() hook
  client.tsx         # client entry (hydrateStart)
  ssr.tsx            # server entry (createStartHandler)
  router.tsx         # createRouter() + type registration
vite.config.ts       # Vite 7 + @tanstack/react-start plugin — SPA preset, optimizeDeps
```

## Provider Stack

Providers are layered in `__root.tsx` in this order (outermost first):

1. `ChakraProvider` — Chakra UI v3 with `defaultSystem`
2. `QueryClientProvider` — TanStack Query client
3. `DuckDBProvider` — DuckDB-WASM instance + connection

## DuckDB-WASM Notes

- Initialized client-side only via `useEffect` in `DuckDBProvider`
- Uses jsDelivr CDN bundles (`getJsDelivrBundles`) — no local WASM files to manage
- `SharedArrayBuffer` is required; production COOP/COEP headers are set via `vercel.json`
- `@duckdb/duckdb-wasm` is excluded from Vite pre-bundling (`optimizeDeps.exclude`) to avoid bundling its dynamic worker imports
- `useDuckDB()` returns `{ db, conn, loading, error }` — always check `loading` before querying

## Routing

File-based routing via TanStack Router. Add a file under `app/routes/` and run `npm run codegen` (or leave `npm run dev` running — it watches automatically). Route files must export a `Route` const created with `createFileRoute`.

| `@tanstack/react-table` | Headless table primitives |
